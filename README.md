# Lopus Client

**Xây bản vẽ Litematica, từng tầng một.**

Mod Fabric cho Minecraft Java 1.21.11 · Phiên bản 1.2.5 Beta · Giấy phép MIT

Chọn bản vẽ, bật mod, rồi để Lopus Client lo phần còn lại: đứng đúng chỗ, đặt đúng block, hết vật liệu thì tự ra rương lấy. Bạn không cần đứng canh từng block.

## ✨ Tính năng

| | |
|---|---|
| **Đặt block chính xác** | Đúng hướng và đúng trạng thái: repeater, comparator, hopper, cầu thang, slab, trapdoor, observer, piston. Rương đôi được ghép đủ hai nửa. |
| **Xây từng tầng Y** | Xong tầng này mới sang tầng sau, hợp với mạch Redstone cần đúng thứ tự. |
| **Hai chế độ** | **Strict** xoay góc nhìn mượt, giữ tầm với trong 4,5 block. **Fast Place** đặt nhanh hơn, chỉnh 1 đến 5 tick mỗi block. |
| **Tự đi bộ** | Tự tìm chỗ đứng đặt được block kế tiếp và đi tới đó. Có thể dùng `/home` để thoát khi bị kẹt. |
| **Rương tiếp tế** | Nhìn vào rương, thùng, shulker box hoặc ender chest rồi bấm `G`. Hết vật liệu thì nhân vật tự đi lấy đúng loại cần dùng rồi quay lại chỗ đang xây. Dùng được nhiều rương. |
| **Tự đào block sai** | Chọn công cụ đào nhanh nhất. Không đào nhầm slab đơn, rương đôi đang đặt dở hay repeater chờ chỉnh delay. |
| **Giàn giáo** | Đặt tối đa hai block kê tạm cho khối lơ lửng, xong thì thu hồi. |
| **Bộ lọc block** | Whitelist hoặc blacklist. Mặc định bỏ qua TNT, bedrock, barrier, spawner, command block, lava và lửa. |
| **HUD** | Hiện BPS, thời gian còn lại, đường chỉ tới block kế tiếp, đánh dấu rương. Bốn theme: Orchard, Clarity, Rainbow, Gold. |
| **Profile** | Lưu nhiều bộ cài đặt và đổi nhanh. |
| **Tiện ích** | Dọn rác trong rương, tự ăn, tự về home khi rơi, quét xung quanh khi chờ. |
| **Nhạc và Discord** | Phát `.mp3` và `.wav` ngay trong game (chạy được trên Zalith, PojavLauncher). Discord Rich Presence. |
| **Ngôn ngữ** | Tiếng Việt và English. |

## 📦 Cài đặt

**Cần có:** Minecraft Java 1.21.11 · Fabric Loader 0.16.0+ · Java 21+

1. Cài [Fabric Loader](https://fabricmc.net/use/) cho Minecraft 1.21.11.
2. Cho **Fabric API** vào thư mục `mods`.
3. Cho **Litematica** và **MaLiLib** (bản dành cho 1.21.11) vào thư mục `mods`.
4. Tải file **`litematica-autobuild-printer-*.jar`** ở trang này và cho vào thư mục `mods`.
5. Vào game, nhấn **Right Shift** để mở menu Lopus Client.

> Mod chạy phía client, server không cần cài gì thêm.

## ⌨ Phím tắt

Mặc định như sau, đổi được trong *Options → Controls → Lopus Client*.

| Phím | Chức năng |
|---|---|
| `Caps Lock` | Bật/tắt máy in |
| `Right Shift` | Mở menu |
| `G` | Chọn rương tiếp tế |
| `U` | Đổi giữa Strict và Fast Place |
| `J` | Bật/tắt xây từng tầng |
| `K` | Bật/tắt giàn giáo |
| `I` | Bật/tắt tự đào block sai |
| `O` | Bật/tắt tự đi bộ |
| `P` | Đổi tốc độ đặt (1 đến 5 tick) |

## English

**Lopus Client** is a Fabric mod for Minecraft Java 1.21.11 that builds Litematica schematics layer by layer. It stands in the right spot, places each block in the right state, and fetches more materials from a chest when you run out.

**Highlights:** exact block-state placement (repeaters, comparators, hoppers, stairs, double chests and more) · layer-by-layer building · Strict and Fast Place modes · A* auto-walk · automatic chest restocking · digs up wrong blocks · scaffolding for floating blocks · block whitelist/blacklist · HUD with BPS and ETA · multiple profiles · built-in .mp3/.wav player · Discord Rich Presence · Vietnamese and English UI.

**Install:** install Fabric Loader 0.16.0+ and Java 21+, put Fabric API, Litematica, MaLiLib (for 1.21.11) and the `litematica-autobuild-printer-*.jar` from this page into your `mods` folder, then press **Right Shift** in game.

**Use responsibly.** The mod automates placing and breaking blocks. Many servers forbid this. Check the server rules before using it.
